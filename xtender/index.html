Before you install — please read

RSL-Xtender is a brand-new independent app, so Windows and some antivirus software don't recognize it yet and may show scary-looking warnings. These are false positives — the app is safe. Here's how to get through them:

  1. Your browser may block the download. If it says the file “isn't commonly downloaded” or “may be dangerous”, click the “⋯” / arrow next to it and choose Keep (or Keep anyway).
  2. Windows SmartScreen may pop up when you run the installer (“Windows protected your PC”). Click More info, then Run anyway.
  3. Your antivirus may flag it. If the installer disappears or is quarantined, restore it and add an exception for RSL-Xtender, then run it again.

These warnings fade over time as the app builds reputation. Still unsure? Ask us on Discord before installing.
